**Who this is for:** Release viewers (NRMS.Viewer).

You see a release as a release editor does, without **Actions**, the "Not ready" line and **Similar published releases**, and you can't change anything.

At the top are its type, status, reference number and headline. Under them you may see:

- "This release failed" and the reason, if publishing didn't work;
- **Flickr alert**, if the release went out without its Flickr photo.

If you see "This page updates on its own until the release is done — no need to reload.", the release is being published or taken off the site. Its status changes by itself.

On a wide screen, the release is on the left, and **Publish settings** and **Release info** are on the right. On a narrow screen they come one after another.

## The release

- **Documents**: each document's layout, such as "Layout: Formal", then its **Page title**, **Headline**, **Subheadline**, **Body** and **Contacts**. A Formal document has **Organizations**; an Informal one has a **Byline**. If a document has French text, choose its **French** tab to read it.
- **Page details**: the **URL key**, **Redirect URL**, **Location**, **Summary**, **Social media summary** and **Keywords**.
- **Categories**: the ministries, sectors, themes and tags it is filed under. Choose **Show categories** to see every choice.
- **Top / Feature**: where the release is a Top or Feature on the public site, such as "Top on Home". Choose **Show Top / Feature** to see every place.
- **Media asset**: the photo or video shown with the release, or "No media asset set."
- **Files**: translations and media files. Choose a file's name to open it.

## Publish settings

- **Calendar activity ID**: the Calendar activity the release is linked to. Under it you see the activity's title, which opens it in the Calendar. If you can't see that activity in the Calendar, it says "Calendar activity 3: its details aren't shown to you.", with the activity's number.
- **Planned publish date (for planning only)**: the date and time a release editor plans to publish it, if there is one. Nothing is published at that time unless they schedule it.
- Whether it goes to News On Demand subscribers, and the **Media distribution lists** ticked to get it. "As saved, these lists won't get the media email." means a release editor still has to save its settings for them to.

## Release info

- **Key** and **Reference (NEWS number)**, or "(none yet)".
- **View on site** opens the public page in a new tab. It works only while the release is published. The public news site has its own **Search** page and a **Connect** page.
- **View PDF** opens the release as a PDF in a new tab.
- **Email me a copy** emails the release to you. You see "Sent to" and your address. The release's **History** records that you did.
- **History** lists what was done and by whom. Tick **Show all** to include every edit.
- **Published copies** lists each time it went out.

If you see "This release doesn't exist, or has been deleted.", it was deleted, or the link you followed is wrong.

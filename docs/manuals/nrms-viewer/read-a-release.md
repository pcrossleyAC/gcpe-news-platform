**Who this is for:** Release viewers (NRMS.Viewer).

You see a release just as a release editor does, but you can't change anything and there is nothing to save.

At the top are its type, status, reference number and headline. A draft may also list what is still missing, under "Before this can be approved:" or "Before this can be published:". Those lists are for the release editor.

If you see "This page updates on its own until the release is done — no need to reload.", the release is being published or taken off the site. Its status changes by itself.

On a wide screen, the release is on the left, and **Publish settings** and **Release info** are on the right. On a narrow screen they come one after another.

## The release

- **Documents**: each document's page title, headline, body and contacts. If a document has French text, choose its **French** tab to read it.
- **Page details**: the URL key, location, summary, social media summary and keywords.
- **Categories**: the ministries, sectors, themes and tags it is filed under. Choose **Show categories** to see every choice.
- **Top / Feature**: where the release is a Top or Feature on the public site, such as "Top on Home". Choose **Show Top / Feature** to see every place.
- **Media asset**: the photo or video shown with the release, if it has one.
- **Files**: translations and media files. Choose a file's name to open it.

## Publish settings

**Publish settings** shows the planned publish date, if there is one. It also shows whether the release goes to News On Demand subscribers, and which media distribution lists it is sent to.

## Release info

- **Key** and **Reference (NEWS number)**, or "(none yet)".
- **View on site** opens the public page in a new tab. It works only while the release is published.
- **View PDF** opens the release as a PDF in a new tab.
- **Email me a copy** emails the release to you. You see "Sent to" and your address. The release's **History** records that you did.
- **History** lists what was done and by whom. Tick **Show all** to include every edit.
- **Published copies** lists each time it went out.

If you see "This release doesn't exist, or has been deleted.", it was deleted, or the link you followed is wrong.

## The public news site

**View on site** takes you to the public news site. The site has a page for every ministry, sector, theme and tag, each with its latest 20 posts and an RSS feed. Older news is in the archive, one page per month. Each ministry page also shows its minister, its media contacts, the ministry's website, and its featured topics and services.

The site's **Search** page searches every published post. You can narrow it by **Ministry**, **Sector**, **Content** or **Date**. Each ministry and sector page links to it.

The **Connect** page lists the government's social media accounts and the site's RSS feeds.

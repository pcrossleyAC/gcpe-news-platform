**Who this is for:** Release viewers (NRMS.Viewer).

On **Website** you see two tabs. Both only show information.

## What's featured where

The table lists each place on the public site that has a Top or Feature release: **Home**, and each ministry, sector or theme page. **Top** and **Feature** show the release's headline. A dash means the spot is empty. If nothing is set anywhere, the tab says "Nothing is currently Top or Feature anywhere."

Choose a headline to open the release. Release editors choose the Top and Feature releases.

## Website log

**Website log** lists every change to the public site's content, newest first: **When**, **Who**, **Area** and **What**. It shows the latest 200 entries.

To see one kind of change, choose it in **Filter by area**, such as **Features** or **Carousel**. Choose **(all)** to see everything again.

Release editors make the **Features** changes. Site editors make the others, except **Project Blue Bridge**, which only Core administrators change.

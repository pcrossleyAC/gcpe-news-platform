**Who this is for:** Release viewers (NRMS.Viewer).

## Open a release you know

1. Type into **Find a release**, at the top of the side menu, one of:
   - its reference number, such as NEWS-00007, or just 00007;
   - its release number or URL key, such as 2026HLTH0003-000008;
   - its public web address.
2. Choose **Find**.

The release opens. If nothing has that number, you get **Search** results for what you typed instead.

## Search

1. Choose **Search** in the side menu.
2. Type part of the headline in **Search**, word for word. Capitals don't matter.
3. To narrow it, choose a **Ministry** or **Sector**. On its own, without words in **Search**, this does nothing.
4. Choose **Search**.

Typing a reference number, release number or web address here opens the release directly, as **Find a release** does.

Before you search, **Search** lists the five most recently published releases.

Results include drafts, scheduled and published releases, newest first, 20 to a page. Deleted releases don't appear. If nothing matches, you see "No releases match" and your words. If a ministry or sector is chosen, choose **Clear ministry and sector filters** to try again without them.

Search looks at headlines only. To find a published release by other words, use the public site's own **Search** page.

To find the releases linked to a Calendar activity, search for its reference with a ministry prefix, such as HLTH-123. If no release is linked to it, or you can't see that activity in the Calendar, you also get the releases with those words in the headline. So COVID-19 finds headlines that mention COVID-19.

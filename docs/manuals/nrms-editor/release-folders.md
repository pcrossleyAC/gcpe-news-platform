**Who this is for:** Release editors (NRMS.Editor).

**Releases** has four tabs. **Releases** in the side menu opens the tab you had open last, or **Drafts**.

| Tab | What it lists | In what order |
|---|---|---|
| **Forecast** | Releases planned or scheduled from now on, and the Calendar activities a release may be planned for. | By time. |
| **Drafts** | Releases not yet scheduled or published: drafts, approved releases and failed ones. | Those planned for today or earlier first, then those with no planned time, then later ones. |
| **Scheduled** | Releases set to publish at a time. | Soonest first. |
| **Published** | Releases on the public site, and advisories that have been sent. | Newest first. |

Each row shows the type, the page title, if it isn't the same as the type, the lead ministry, the status, the date, the Calendar activity it is linked to, and on **Drafts** who changed it last. Choose the headline to open the release.

To see one kind only, choose it in **Type**: **Release**, **Story**, **Factsheet** or **Advisory**. The Hub remembers your choice on every tab. If nothing matches, choose **Show every type**.

Each page shows 25 releases. Use **Previous** and **Next** to move between pages.

## What the status means

| Status | Meaning |
|---|---|
| **Draft** | Not yet approved. |
| **Approved** | Approved: it has a reference number. It can be published or scheduled. |
| **Planned** | It has a planned publish date in **Publish settings**, but nothing is committed. A planned release that is approved also shows an **Approved** badge. |
| **Scheduled** | It will publish at the time shown. |
| **Publishing...** | Its time has come and it is going out now. |
| **Republishing...** | A saved correction is going out. |
| **Published** | It is on the public site. An advisory shows **Sent** instead. |
| **Unpublishing...** | It is being taken down. |
| **Failed** | Publishing didn't work. Open it to see why. |

A **Flickr alert** badge means the release went out without its Flickr photo. See [Photos, video and files](manual:editor-files-and-media).

## The Forecast

**Forecast** shows what is coming, so you can see what is already planned before you start something new.

Calendar activities appear only if you have Calendar access, and only the ones you can see in the Calendar. They must be confirmed, not confidential, start from now on, and have a category starting with "Approved". An activity that already has a release planned or scheduled is shown as that release instead. Without Calendar access the tab says "Calendar activities are listed here for people with Calendar access. Ask a Calendar administrator if you need it."

Each activity shows its planned time and its **Calendar activity ID**. Choose **Start a release** under an activity to start a release from it. See [Start a release](manual:editor-start-a-release).

**Who this is for:** Release editors (NRMS.Editor).

On **Website** you see two tabs. Both only show information.

## What's featured where

The table lists each place on the public site that has a Top or Feature release: **Home**, and each ministry, sector or theme page. **Top** and **Feature** show the release's headline. A dash means the spot is empty. If nothing is set anywhere, the tab says "Nothing is currently Top or Feature anywhere."

Choose a headline to open the release. You set Top and Feature on the release itself; see [Correct, unpublish or delete](manual:editor-correct-unpublish-delete).

## Website log

**Website log** lists every change to the public site's content, newest first: **When**, **Who**, **Area** and **What**. It shows the latest 200 entries. Your Top and Feature changes appear under **Features**, such as "Set as Top for Home".

To see one kind of change, choose it in **Filter by area**. Choose **(all)** to see everything again.

The other areas, such as **Carousel** and **Site settings**, are changed by site editors.

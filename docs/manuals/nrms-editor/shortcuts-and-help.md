**Who this is for:** Release editors (NRMS.Editor).

## Keyboard shortcuts

On a Mac, use Command instead of Ctrl. The shortcuts work from inside text boxes too.

| Keys | What it does |
|---|---|
| Ctrl+S | On a release, saves every part you changed, the same as **Save changes**. |
| Ctrl+Enter | On **New release**, the same as **Create release**. |
| Ctrl+K | Goes to the search or filter box: **Type** on the folders, the **Search** box on **Search**, and **Find a release** everywhere else. |
| Esc | Closes a box or an open panel. Focus goes back to the button that opened it. |

In a box that asks you to confirm, Enter and Esc work as usual.

## Help

**Help**, at the top of every screen, opens the page of this manual for the screen you are on. On a screen this manual doesn't cover, it opens the Help page.

The Help page has:

- **Manuals**: the manuals you can open.
- **How do I…**: short answers for common tasks.
- **Keyboard shortcuts**: the full list.
- **Glossary**: what terms such as **Planned publish date** and **Media distribution lists** mean.

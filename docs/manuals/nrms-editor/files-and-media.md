**Who this is for:** Release editors (NRMS.Editor).

Advisories have no media asset, translations or media files.

## The main photo or video

**Media asset** holds the one photo or video shown with the release.

1. Paste a YouTube or Flickr link, or https://news.gov.bc.ca/live, into **Asset URL**.
2. Enter **Alt text**: a short description of the photo or video for people who can't see it, up to 149 characters.
3. Choose **Save changes**.

Under the heading you then see what it is: "YouTube video.", "Live broadcast embed." or, for a Flickr photo, one of these:

| Message | What it means |
|---|---|
| "Public on Flickr." | Ready. |
| "Private — will be made public when the release publishes." | Leave it. Publishing makes it public. |
| "This photo no longer exists on Flickr." | Check the link, or choose another photo. |
| "Flickr can't be reached right now." | Try again later. You can still publish; see below. |

Links that are refused when you save:

| Message | What to do |
|---|---|
| "Facebook is no longer supported due to privacy concerns. Use YouTube or Flickr URLs instead." | Use a YouTube or Flickr link. |
| "Use a YouTube or Flickr URL, or https://news.gov.bc.ca/live." | Other sites can't be used. |
| "That Flickr link doesn't point to a photo." | Use the link to one photo, not an album or profile. |

## If Flickr is down when the release publishes

- At the publish time, the Hub tries to make the photo public for up to 2 minutes.
- If it can't, it goes out up to 2 minutes late, without the photo. The release and its row in the folders show a **Flickr alert**, and an alert email goes to the people set up to receive Flickr alerts.
- The Hub keeps trying for 24 hours. When the photo becomes public, the release republishes with it by itself. Nobody is emailed again.
- If it still fails after 24 hours, the alert says "The release is live without it — re-add or replace the photo." Change the **Asset URL** and save.

## Translations and media files

**Files** holds files people can open from the public release. On an advisory it says "An Advisory has no translations or media files." and offers no upload.

- **Translations**: PDFs, such as the release in French or another language. Choose **Upload a translation (PDF)** and pick the file.
- **Media files**: PDF, PNG or JPEG files, such as a photo or a fact sheet. Choose **Upload a media file** and pick the file. **Includes additional media assets** in **Media asset** is ticked for you.

Each file can be up to 25 MB. A larger file isn't uploaded. A file is saved as soon as it is uploaded; you don't need **Save changes**. Choose a file's name to open it.

Files can be opened by the public only while the release is published. Before then, and after an unpublish, only Hub staff can open them.

To remove a file, choose **Remove** and its name, then **Confirm remove**. This can't be undone.

| Message | What it means |
|---|---|
| "This file isn't a PDF." | Translations must be PDFs. |
| "Upload a PDF, PNG or JPEG file." | Media files must be one of those. |
| "The file is empty." | Pick the file again. |
| "photo.jpg is too large to upload. A file can be at most 25 MB." | The file is over 25 MB. Make it smaller. |
| "A file can be at most 25 MB." | The same, found while uploading. |

Uploading or removing a file on a published release republishes it at once, as a correction.

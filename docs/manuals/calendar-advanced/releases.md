**Who this is for:** Calendar advanced users (Calendar.Advanced).

Release editors plan news releases from Calendar activities in **Releases**. A release can be linked to an activity, and the activity then shows that release.

## BC Gov News on an activity

**BC Gov News**, at the end of the **Release** section, lists the releases linked to the activity, or says "No releases are linked to this activity."

Each line gives the release's type, its number when it has one, its status and its date, such as "Release: Draft". The status is **Draft**, **Approved**, **Scheduled**, **Published** or **Failed**. It changes within a minute of the change in **Releases**.

- A release being corrected or taken down still shows **Published** until that is done.
- A deleted release disappears from the list.
- If you also have a role in **Releases**, each line opens the release. Otherwise it is plain text.

In the activity list, **Release** in the **Activity Id** column means a release is linked.

## Which activities release editors see

Release editors see Calendar activities on **Releases** > **Forecast** only if they also have Calendar access, and only the activities that access lets them see. An activity appears there when all of these are true:

- its category starts with "Approved", such as **Approved Release**;
- **Dates Confirmed** is ticked;
- it isn't marked **Not for Look Ahead**;
- it starts from now on, and isn't deleted.

From the **Forecast**, a release editor can start a release for the activity. The release can copy the activity's start, city, lead and shared ministries, sectors, themes and **News Subscribe** topics.

## What your changes do

- Your changes reach **Releases** within a minute.
- Changing an activity doesn't change a release already linked to it. What was copied into the release stays as it was. Tell the release editor if the release needs to change.
- Marking an activity **Not for Look Ahead** takes it off the **Forecast**. A release editor who types its number sees, for example, "Calendar activity 3: its details aren't shown to you."
- A deleted activity leaves the **Forecast**, and no release can be linked to it from then on.
- Nobody is emailed.

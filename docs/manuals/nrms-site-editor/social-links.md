**Who this is for:** Site editors (NRMS.SiteEditor).

**Social links** sets the public Connect page, which lists the government's social media accounts by network. Open it from **Website** > **Site settings** > **Social links**. It changes the public site only when you publish. See [How site settings are published](manual:site-settings).

## The top of the Connect page

Under **Connect page**, all three boxes are optional:

- **Policy link text** and **Policy link URL**: a link shown on the Connect page, such as a social media policy. Fill in both, or neither. An address on the Hub itself shows "This address points at the Hub, which the public can't open. On Website → Files, use Copy public address and paste that instead." under **Policy link URL**, for every web address of the Hub's server.
- **Introduction**: plain text shown above the networks, up to 300 characters.

## A network's accounts

Each network has a tab: **Facebook**, **X**, **Instagram**, **Threads**, **Bluesky**, **LinkedIn**, **Flickr**, **YouTube** and **Blogs**. The number beside each name is how many links it has. A network with no links is left off the Connect page.

Save a draft before you switch tabs. Unsaved changes on the tab you leave are lost.

1. Choose the network's tab.
2. Under **Featured accounts**, choose **+ Add a link** and fill in **Link text**, **Web address** and, if you like, **Description (optional)**. Featured accounts show first, in the order you set with **Move link 1 up** and **Move link 1 down**.
3. Under **Other accounts**, add the rest the same way. They show after the featured ones, sorted by name.
4. In **Entries shown before Expand**, enter how many links show before the network's Expand button. Enter 0 to show them all, or leave it empty for the standard number given in the hint.
5. Choose **Save draft**, then go on to the next network, or choose **Publish**.

## What happens next

The Connect page shows the change within a few minutes.

## Can't do this?

| Message | What it means |
|---|---|
| "Enter the link text." | A link has a web address but no words. |
| "Must start with https:// or / (a page on this site)." | A link's web address is missing, starts with http://, or has a space in it. |
| "Use plain text, 200 characters or fewer." | Shorten the **Description**, and remove any < or > characters. |
| "Keep it to 300 characters or fewer." | Shorten the **Introduction**. |
| "Enter a whole number from 0 to 50." | Fix **Entries shown before Expand**. |

A problem on another network's tab shows in the list of other problems, starting with that network's name, such as "X: Enter the link text."

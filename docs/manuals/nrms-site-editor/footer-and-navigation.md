**Who this is for:** Site editors (NRMS.SiteEditor).

Two settings screens set the wording around every public page: **Footer** for the footer's links, and **Navigation and labels** for the menu, buttons and headings. Open them from **Website** > **Site settings**. Both change the public site only when you publish. See [How site settings are published](manual:site-settings).

## Footer

The screen is titled **Footer links**.

- **Help text**: a short line in the footer, plain text, up to 200 characters.
- **Help links**, **Connect with Us links** and **More Info links**: the footer's link lists.
- **Copyright holder**: shown as "© 2026 Government of British Columbia", with the current year added for you.
- **Land acknowledgement**: shown in a band above the footer on every page. Leave it empty to hide the band.

To change a list:

1. Choose **+ Add a link** under the list, then fill in **Link text** and **Web address**.
2. Use **Move link 1 up**, **Move link 1 down** and **Remove link 1** to arrange it.
3. Choose **Publish**.

A footer column shows only when it has links. Its heading is on **Navigation and labels**.

A footer change reaches every page over the following minutes, not all at once.

## Navigation and labels

Every wording box is required, except the two footer headings.

- **Header**: **News menu label**, **Live webcast button label**, up to 4 **Header links** after the news menu, and **Show the search box in the header**.
- **Footer headings**: **Footer: Connect with Us column heading** and **Footer: More Info column heading**. Leave one blank for no heading.
- **Page labels**: headings and link words on the home page and news lists, such as **Resources heading**, **Emergency information heading** and **Load more news button label**. The hint under each box says where it appears. Two are never shown on screen; screen readers read them aloud: **Slideshow name (read aloud by screen readers)** and **Home page main heading (hidden, for screen readers)**.
- **Slide link label (when a slide has none)**: the link words for a carousel slide or emergency notice whose own **Action label** is empty.
- **Listing titles**: the titles of the releases, stories, factsheets and updates pages.

Change the wording, then choose **Publish**.

The site's name and logo in the header are not set here. The support team sets them.

## Can't do this?

| Message | What it means |
|---|---|
| "Enter text for this field." | A required box is empty. |
| "Keep it to 60 characters or fewer." | Shorten the wording. The limit depends on the box. |
| "Use plain text." | Remove < and > from the wording. |
| "Keep the list to 4 or fewer." | There are more than 4 header links. |
| "Enter the link text." | A link has a web address but no words. |
| "Must start with https:// or / (a page on this site)." | A link's web address is missing, starts with http://, or has a space in it. |
| "Enter who holds the copyright." | **Copyright holder** is empty. |
| "Keep the help text to 200 characters or fewer." | Shorten **Help text**. |

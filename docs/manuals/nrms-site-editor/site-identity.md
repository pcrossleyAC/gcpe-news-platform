**Who this is for:** Site editors (NRMS.SiteEditor).

**Site identity** sets how the public site describes itself to search engines and link previews, and the wording of the Project Blue Bridge banner. Open it from **Website** > **Site settings** > **Site identity**. It changes the public site only when you publish. See [How site settings are published](manual:site-settings).

The site's name and the BC logo are not set here. The support team sets them.

## Change the site description or X account

- **Site description**: what search engines and link previews show for pages without their own summary. Keep it to about 150 characters; the limit is 300.
- **X (Twitter) account**: shown in link previews, such as @BCGovNews. Leave it empty for none.

Change the box, then choose **Publish**.

## Project Blue Bridge

When the King dies, a Core administrator puts the public site into mourning with Project Blue Bridge: a black banner on every page and a mourning theme. Only a Core administrator can turn it on or off, and only with approval from the Intergovernmental Relations Secretariat (IGRS).

You prepare its wording, under **Project Blue Bridge banner**:

- **Banner message**: shown on every page while it is on. Type {age} where the King's age in years should go. No other placeholder in braces is allowed.
- **Birth date**: used to work out {age}. It is needed only when the message uses {age}.

Change them, then choose **Publish**. Check them ahead of time: once the switch is on, the banner shows whatever was last published here.

**Website** > **Site settings** > **Project Blue Bridge** shows whether it is on: "Project Blue Bridge is currently OFF." (or ON). You see no switch there. While it is on, your own [site banner](manual:site-banner) is hidden.

## Can't do this?

| Message | What it means |
|---|---|
| "Keep it to 300 characters or fewer." | Shorten the description or the banner message. |
| "Use plain text." | Remove < and >, and line breaks, from the box. |
| "Enter an X account like @BCGovNews." | The account has spaces, or characters other than letters, digits and _, or is longer than 15 characters. |
| "Enter text for this field." | **Banner message** is empty. |
| "The only placeholder is {age}." | The message has another word in braces. Use only {age}. |
| "Enter a date like 1948-11-14." | The message uses {age} and **Birth date** is empty, or the date given is in the future. |

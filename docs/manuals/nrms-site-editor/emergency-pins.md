**Who this is for:** Site editors (NRMS.SiteEditor).

**Emergency pins** holds two emergency notices, **Primary** and **Secondary**. A pinned notice shows on the public home page under the **Emergency information** heading, above the news. An unpinned one is kept here but not shown.

Each notice has the same fields as a carousel slide: headline, summary, action URL, action label, Facebook post URL, justify and an image.

## Write a notice

1. Fill in the notice's fields, such as **Primary headline** and **Primary summary**.
2. Choose **Save primary pin** (or **Save secondary pin**).

If the notice is already pinned, the change goes to the public site when you save. Under the notice you see "Saved at 2:30 PM. Live now: the home page shows it within a few minutes." (with the time). An unpinned notice says "Saved at 2:30 PM. Not on the home page: this notice isn't pinned."

To link to a file from **Files**, paste the address from its **Copy public address** button into the action URL. An address copied from the Hub itself shows "This address points at the Hub, which the public can't open. On Website → Files, use Copy public address and paste that instead."

## Pin or unpin a notice

Save the notice first. If you have typed changes you haven't saved, the switch does nothing and shows "Save your changes first." Your typing stays.

1. Choose the switch beside **Primary is not pinned**, below **Save primary pin**. It saves at once, with no question, and changes only the pin; it now reads **Primary is pinned**, and you see "Pinned at 2:30 PM. Live now: the home page shows this notice within a few minutes."
2. To take the notice down, choose the switch again. You see "Unpinned at 2:30 PM. The home page stops showing this notice within a few minutes."

## Add or change the image

1. Choose **Primary image (JPEG or PNG, up to 2 MB)** and pick the file.
2. It saves at once, and the new image shows above the button straight away. You see "Image saved at 2:30 PM." On a pinned notice the public site changes too, and the message adds "Live now: the home page shows it within a few minutes."

## What happens next

- The public home page shows the change within a few minutes.
- Every save, pin and unpin is listed in **Website log** under **Emergency pins**.

## If you leave before saving

If you have changes you haven't saved and you go to another screen or choose your browser's **Back**, the Hub asks "You have unsaved changes on this page. Leave anyway and discard them?" Choose **Stay** to keep working, or **Leave** to discard the changes. Closing or reloading the tab gets your browser's own question.

## Can't do this?

| Message | What it means |
|---|---|
| "Add a headline before pinning." | The saved notice has no headline. Enter one, choose **Save primary pin**, then pin it. |
| "Primary: Enter a full web address for Action URL, starting with http:// or https://" | The web address in the action URL (or Facebook post URL) is wrong. Start it with http:// or https://, or empty the box. Nothing is saved until it is right. |
| "Keep the action label to 40 characters or fewer, in plain text." | Shorten the action label, and remove any < or > characters. |
| "Upload a JPEG or PNG image." | The file isn't a JPEG or PNG image. |
| "That image is over 2 MB. Choose a smaller image." | Make the image smaller and try again. |
| "Save your changes first." | You changed the notice and then used the pin switch. Choose **Save primary pin** (or **Save secondary pin**), then use the switch. |
| "Someone else changed this — reload to see their changes." | Another site editor changed this notice while you had the page open. Choose **Reload**. |

**Who this is for:** Site editors (NRMS.SiteEditor).

You run what the public news site shows around the news releases: the home page carousel, emergency notices, links, files, the banner, the footer, colours and wording. You also keep each ministry's minister and contact details up to date.

## What only you can do

Release editors and release viewers can open **Website**, but they see only **What's featured where** and **Website log**. Core administrators see every **Website** tab but can't change anything except Project Blue Bridge. Everything below is yours.

| Screen | What it controls | When visitors see it | Help page |
|---|---|---|---|
| **Website** > **Carousel** | The slides at the top of the home page, and the next set of slides with its go-live time. | A few minutes after you publish, or after the next set's go-live time. | [Carousel](manual:carousel) |
| **Website** > **Emergency pins** | Two emergency notices you can pin to the home page. | A few minutes after you save a pinned notice, or pin it. | [Emergency pins](manual:emergency-pins) |
| **Website** > **Live Feed** | The Live Webcast button and the stream it plays. | A few minutes after you save. | [Live Feed](manual:live-feed) |
| **Website** > **Resource links** | The list of links on the home page. | A few minutes after you save. | [Resource links](manual:resource-links) |
| **Website** > **Files** | Files the public can open at a fixed web address, such as PDFs and minister photos. | As soon as the upload finishes. | [Files](manual:website-files) |
| **Website** > **Hub address check** | Nothing: it lists saved web addresses that point at the Hub, which visitors can't open, so you can fix them. | Not shown to visitors. | [Hub address check](manual:hub-address-check) |
| **Website** > **Site settings** | The banner, footer, social links, colours, headings, page wording, menu and site description. | A few minutes after you publish. | [How site settings are published](manual:site-settings) |
| **Organizations** | Each ministry's name, minister, biography, media contacts and page links. | Within a few minutes of saving. | [Organizations](manual:site-editor-organizations) |

**What's featured where** and **Website log** are read-only for everyone. See [What's featured where and the Website log](manual:featured-and-website-log).

## What you see in the side menu

Under **Work** you see **Releases**, **Search** and **Website**. Under **Administration** you see **Organizations**.

On **Releases** and **Search** you can read releases but not change them. Choosing a release's Top or Feature spot is done on the release itself, by release editors. To write or publish releases, ask a Core administrator for the release editor role as well. The [Releases editor manual](manual:nrms-editor) and the [Releases viewer manual](manual:nrms-viewer) cover release work.

## Signing in and unsaved changes

The Hub keeps you signed in while its tab is open. [Staying signed in, and unsaved changes](topic:signing-in-and-unsaved-changes) says what happens when your session ends, and how the Hub asks before you lose changes you haven't saved.

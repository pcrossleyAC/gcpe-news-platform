**Who this is for:** Site editors (NRMS.SiteEditor).

These two **Website** tabs only show information. Release editors and release viewers see them too.

## What's featured where

The table lists each place on the public site that has a Top or Feature release: **Home** and each ministry, sector or theme page. **Top** and **Feature** show the release's headline. A dash means the spot is empty.

On the public home page, the Top and Feature releases appear above the latest news.

Choose a headline to open the release. Release editors set Top and Feature on the release itself; you can't change them here. If nothing is set anywhere, the tab says "Nothing is currently Top or Feature anywhere."

## Website log

**Website log** lists every change to the public site's content, newest first: **When**, **Who**, **Area** and **What**. It shows the latest 200 entries.

To see one kind of change, choose it in **Filter by area**: **Carousel**, **Emergency pins**, **Live Feed**, **Project Blue Bridge**, **Resource links**, **Files**, **Features** or **Site settings**. Choose **(all)** to see everything again.

Use it to check who changed something and when, for example "Published revision 4: Election notice" under **Site settings**.

**Who this is for:** Core administrators (Core.Admin).

**Release page titles** lists the titles a new release can choose, such as News Release or Information Bulletin. The title shows above the headline on the public release page.

Titles are grouped by release type: Release, Story, Factsheet, Update and Advisory. Each row has a **Page title**, **Language** (English or French), **Order**, **Layout** (Formal or Informal) and **Page image**.

## Change a page title

1. Change the fields on the row.
2. Choose **Save** on that row. You see "Saved {title}."

## Add a page title

1. Under **Add a page title**, choose the **Type**.
2. Enter the **Page title**: up to 50 characters, without < or >.
3. Choose the **Language**. Release editors choosing a title on **New release** see the English titles.
4. Leave **Order** as suggested, or change it. Lower numbers come first.
5. Choose the **Layout** and **Page image** that a new release with this title starts with. A Formal document has an organizations line; an Informal document has a byline.
6. Choose **Add page title**. You see "Added {title}."

## Delete a page title

1. Choose **Delete** on its row. The Hub asks "Delete {title}?" and explains "New releases can no longer choose it. Releases that already use it keep it."
2. Choose **Delete**.

## What happens next

- Release editors see the change the next time they open **New release**.
- A release keeps the title it was given. To change a published release's title, edit that release.

## Can't do this?

| Message | What it means |
|---|---|
| "Page title is required." | Enter a title. |
| "Page title can't contain < or >." | Remove those characters. |
| "Order must be a whole number from 0 to 9999." | Fix the order. |
| "A page title with that name already exists in that language." | Choose another title, or edit the existing one. |
| "This is the only English page title for {type}. Add another first." | Each release type needs at least one English title. Add the new one, then delete the old one. |
| "That page image does not exist." | The image was removed. Choose another one. |
| "That page title no longer exists." | Someone else deleted or renamed it. The list reloads. |
